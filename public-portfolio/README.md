# Outbound Operations — Public Portfolio Demonstration

A separate, static portfolio page based on the structure of the original dashboard. It uses only generic copy and fictional sample data and has no runtime dependency on private systems.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server. No build step, package install, database, API, or credentials are required.

## Deploy to Vercel

Import the repository into your Vercel account and set **Root Directory** to `public-portfolio`. Select **Other** as the framework preset, leave the build command empty, and deploy the static output from that directory. This folder is independently deployable; it does not require the original dashboard's documents, scripts, or assets.

## Public-safety review

The source repository contains confidential-looking material and was not modified. The public folder does not copy or link to the source docs, archives, internal forms/sheets, or campaign subpages. Specifically kept out: named client identity and materials; private Google Form and Sheet URLs; prospect / response data archives; campaign-specific ICP, offer, discovery and messaging documents; scripts; CRM and dialer workflow pages; warehouse specifications; meeting notes; internal launch status, employee names, and locally-referenced files. No source documents or images were reused.

The page contains fictional labels (Campaign A, Prospect 001, SDR 01/02), illustrative example metrics, a sample pipeline, an original generic outreach sequence, and recreated UI panels. Each is explicitly marked as fictional or illustrative. The gallery items are not screenshots of the original application. No original screenshots were supplied; no authentic screenshot is currently approved for public use.
